# TerraForge

> A fully customizable build optimizer and advanced DPS engine for Terraria.

TerraForge goes beyond simple DPS calculators by offering a complete combat simulation engine. It allows players to theorycraft, mix and match accessories, account for enemy I-frames, and min-max their loadouts against specific in-game targets.

## Features
* **Dynamic DPS Simulation:** Accurately calculates damage output accounting for I-frames, enemy defense, and armor penetration.
* **Full Loadout Customization:** Equip weapons, armor, accessories, and ammo.
* **Environmental Modifiers:** (Coming Soon) Factor in day/night cycles, biomes, and world state.

## Tech Stack
* **Frontend:** Vue 3, Composition API, TypeScript, Vite
* **Backend Framework:** Laravel, Inertia.js
* **Database:** Supabase (PostgreSQL)
* **Hosting:** Koyeb (Application / Backend) / Vercel (Frontend / Edge)
